# PSSF — Database Schema

**Version:** 1.0  
**Status:** Approved for implementation  
**ORM:** Prisma + PostgreSQL

---

## Conventions

- All primary keys are `uuid` generated by the database
- All timestamps are `DateTime` in UTC
- Soft deletes use `deleted_at` — no hard deletes on operational tables
- Enum values are stored as strings via Prisma enums
- Foreign keys are always explicitly named
- Every table has `created_at` and `updated_at`

### cases

```prisma
model Case {
  id               String     @id @default(uuid())
  reference        String     @unique
  type             CaseType
  status           CaseStatus @default(DRAFT)
  member_id        String?
  claimant_name    String?
  employer_id      String?
  assigned_to      String?
  form_data        Json
  created_at       DateTime   @default(now())
  updated_at       DateTime   @updatedAt
  submitted_at     DateTime?
  completed_at     DateTime?
  deleted_at       DateTime?

  member           Member?         @relation(fields: [member_id], references: [id])
  employer         Employer?       @relation("EmployerCases", fields: [employer_id], references: [id])
  status_history   CaseStatusHistory[]
  documents        Document[]
  approvals        Approval[]
  tasks            Task[]
  notifications    Notification[]
  audit_events     AuditEvent[]
  notes            CaseNote[]
  beneficiaries    Beneficiary[]
}
```

**Notes on `form_data`:**
The `form_data` JSONB column holds all journey-specific fields that do not warrant their own normalised columns — AVC amounts, benefit option selections, bank details, leaving employment reason, transfer scheme details, death claim home particulars, etc. This keeps the schema clean while preserving all statutory data.

## Case Reference Format

Every case gets a human-readable reference on creation:

```
{TYPE_CODE}-{YEAR}-{SEQUENCE}

Examples:
ENR-2024-000001    Member Enrolment
BEN-2024-000001    Beneficiary Nomination
AVC-2024-000001    AVC
CLM-2024-000001    Benefits Claim
DCL-2024-000001    Death Benefits Claim
MCR-2024-000001    Missing Contribution
DIS-2024-000001    Discrepancy
```
